# 每日一息｜公開網站發布庫

正式網站：https://daycool858000-hue.github.io/daily-pause-public/

此儲存庫包含公開靜態網站的 HTML、CSS、JavaScript 與已發布圖片。公開庫內沒有伺服器端帳號系統；瀏覽器本機資料不會隨 GitHub 程式碼備份。

## 部署與還原

1. 下載此儲存庫的 ZIP，或使用 Git 複製完整儲存庫。
2. 確認 index.html、styles.css、所有 .js 與 media/ 資料夾完整保留。
3. 在另一個 GitHub 儲存庫啟用 GitHub Pages，選擇 main 分支根目錄；也可用靜態 HTTP 伺服器測試。
4. 檢查首頁、五張卡、文章、好奇心抽屜、情緒調色盤、寄放所、圖片載入與本機資料儲存。
5. 此處列的是**還原操作指引**，不是已完成獨立環境還原測試的證明。

## 隱私與維護

- 本站部分偏好與寄放文字儲存在訪客目前使用的瀏覽器；清除網站資料、改用其他裝置或無痕瀏覽可能造成資料消失。請勿將此視為跨裝置備份。
- 全部88則正文的逐段／逐句查核及修正，詳見 [逐段證據](CONTENT_FACT_CHECK_MATRIX_20261012.md)、[逐句索引](CONTENT_SENTENCE_RECHECK_20261012.md)、[現行來源](SOURCE_CURRENT_CROSSWALK_20261012.md) 與 [來源權利界線](SOURCE_RIGHTS_POLICY_20261012.md)。部分原始全文／個別使用授權及裝置實測仍有缺口，詳見 [驗收紀錄](ACCEPTANCE_STATUS.md)。
- 本公開庫不應上傳 API 金鑰、憑證、訪客私人文字或其他機密。
